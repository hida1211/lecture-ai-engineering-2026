# 第3回 解答

使用モデルは `gemini-3.5-flash-lite`。

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素のLLMは宿題の3レベルを一般的な難易度として説明した。エージェントは用語集を検索し、「基礎・実装・発展」と「どれか1つで完了」という講座のルールを回答した。

- `--trace` で見えたツール呼び出し（ツール名と引数）：「LoRAとQLoRAの違いは？」に対して、`search_glossary({"query": "LoRA"})` と `search_glossary({"query": "QLoRA"})` が呼ばれた。

- 1つの質問での LLM 呼び出し回数（`requests`）：上の質問では2回。1回目に2つの検索を選び、2回目に検索結果を基に回答した。ツール呼び出し回数とLLM呼び出し回数は別の値だった。

- 追加したツールと、docstring に書いた説明：`make_quiz(lecture: int)` を追加した。指定回の用語から確認問題を作るツールで、復習問題を求められたときに使うと説明した。実モデルは `make_quiz({"lecture": 2})` を1回呼び、「量子化」の確認問題を出した。

## 宿題

### 基礎

- やったこと：INSTRUCTIONSから用語集の検索を必須にする1行を削除し、同じ「LoRAとQLoRAの違いは？」で変更前後を比較した。モデル、読み取り3ツール、docstring、生成設定（temperature=0、max_tokens=2048）はそろえた。

- 結果：どちらも検索2回、LLM呼び出し2回だった。入力／出力トークンは変更前1374／234、変更後1326／186で、回答の要旨は同じだった。

- 気づき・疑問：docstringにも検索を促す説明が残っており、指示の1行を削除しても検索は減らなかった。

### 実装

- やったこと：`save_learning_log(topic, content)` を追加した。保存前にテーマと本文を表示し、`y` または `yes` の承認があるときだけ保存する。

- 結果：TestModelで、承認前・拒否時には保存されず、承認時だけ1ファイルできることを確認した。全36テストが成功した。

- 気づき・疑問：docstringに「承認を求める」と書くだけでなく、実行側で保存前に止める仕組みが必要だった。

### 発展

- やったこと：同じモデル・指示・読み取り3ツールをADK 2.14.0に設定し、`adk run` で「LoRAとQLoRAの違いは？」への回答をPydantic AI版と比較した。

- 結果：両者とも、LoRAは追加の低ランク行列を学習し、QLoRAは基盤重みの量子化でメモリを節約すると説明した。ADK版はより簡潔で、CLIも正常終了した。

- 気づき・疑問：Pydantic AIは `instructions=` と `tool_plain`、ADKは `instruction=` と `tools=[...]` で設定する。ADKの出力にはtraceがなく、実際のツール呼び出しやLLM呼び出し回数は未確認。エージェントに渡すツールや指示の方法だけでなく、対話や実行方法の違いを確認することができた。
